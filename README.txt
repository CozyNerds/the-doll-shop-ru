The Doll Shop RU 0.1.1 — исходники установщика

Это C#-код установщика. Перевод и бинарные патчи скачиваются отдельно
в архиве TheDollShopRU-0.1.1.zip со страницы GitHub Releases.

СБОРКА

Требуется Windows с .NET Framework 4.x и встроенным компилятором csc.exe.
В папке исходников выполните в Windows PowerShell:

  powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1

Результат: build\Install.exe. Скопируйте его в распакованную папку пакета
для игроков, рядом с package.json и patches. Сам по себе EXE не содержит
перевода и не заменяет игровой пакет.

При сборке из клона или автоматического архива GitHub, а также для другого
пакета обязательно укажите папку с его точным package.json:

  .\Build.ps1 -PackageDirectory "D:\TheDollShopRU"

Build.ps1 встраивает SHA-256 выбранного package.json в скомпилированный EXE.
При изменении манифеста установщик необходимо пересобрать.
Переводы строк также влияют на SHA-256; используйте манифест из архива
для игроков. В отдельном архиве исходников он сохранён в точности.

ФАЙЛЫ

src\Installer.cs       — шаблон исходного кода Windows Forms и движка патча.
src\installer.manifest — манифест Windows и версия 0.1.1.
Build.ps1              — сборка стандартным компилятором .NET Framework.
package.json           — манифест опубликованного пакета 0.1.1, без патчей.
PATCH-FORMAT.txt        — описание бинарного формата.

Установщик использует стандартные библиотеки .NET Framework.
Сборка и установка не обращаются к API перевода и не требуют ключей.
Полные оригинальные или переведённые ресурсы игры сюда не включены.
