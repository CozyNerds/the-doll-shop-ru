# The Doll Shop — русский перевод

[**Скачать русификатор 0.1.1 для Windows / Steam**](https://github.com/CozyNerds/the-doll-shop-ru/releases/download/v0.1.1/TheDollShopRU-0.1.1.zip)

[Все версии и отдельный архив исходников](https://github.com/CozyNerds/the-doll-shop-ru/releases/latest)

Неофициальный перевод диалогов, вариантов ответов, меню, заданий, подсказок и бонусных сцен — 2 443 строки. Добавлена поддержка кириллицы, уменьшен шрифт кнопок меню. Русский занимает прежний английский слот.

## Установка

1. Закройте игру и распакуйте архив целиком.
2. Откройте `Install.exe` и нажмите **«Установить»**.
3. Если игра не найдена автоматически, выберите папку с `TheDollShop.exe`.
4. При запросе прав администратора перезапустите установщик и снова нажмите **«Установить»**.
5. Дождитесь завершения, запустите игру через Steam и при необходимости выберите **«Русский»** в меню языков.

Рядом с `Install.exe` должны остаться `package.json` и папка `patches`. Подробная инструкция находится в `README.txt` внутри архива. Для установки не нужны Python, Кромка, интернет или API-ключи. Требуется примерно 325 МБ свободного места.

## Совместимость и удаление

Поддерживается Windows-версия Steam: **App ID 3851680, сборка 25868400**. Установщик проверяет точную совместимость файлов; после обновления игры может понадобиться новый патч. Можно обновить русификатор 0.1.0, если сохранилась его оригинальная резервная копия.

Для удаления закройте игру и нажмите **«Восстановить оригиналы»** в установщике. Оригиналы сохраняются в `TheDollShopRussian_Backup` рядом с игрой. Сохранения, настройки и прогресс установщик не меняет. Не удаляйте резервную копию, пока пользуетесь переводом.

## О переводе

Машинный перевод через адаптированные промпты Кромки с проверкой по французскому оригиналу и выборочной редактурой. Возможны неточности. Озвучка и надписи внутри изображений не переведены. Игра создана Atelier Sentô; этот проект — неофициальная локализация. Установщик не имеет цифровой подписи издателя.

Пакет содержит бинарные патчи и требует собственных оригинальных файлов поддерживаемой версии игры. Полные ресурсы игры в репозитории и архивах релиза отсутствуют.

## Исходники установщика

В репозитории находится C#-код Windows Forms и движка патча. Инструкция по сборке — в [README.txt](README.txt), описание формата — в [PATCH-FORMAT.txt](PATCH-FORMAT.txt). `Build.ps1` собирает `build/Install.exe` встроенным компилятором .NET Framework, встраивая SHA-256 `package.json`.

При сборке из клона или автоматического архива GitHub укажите путь к распакованному пакету для игроков:

```powershell
.\Build.ps1 -PackageDirectory "D:\TheDollShopRU-0.1.1"
```

Это привяжет EXE к точным байтам манифеста выбранного пакета. Изменение переводов строк в `package.json` тоже меняет его SHA-256. В отдельном архиве `TheDollShopRU-Installer-Source-0.1.1.zip` уже находится точная копия манифеста релиза.

Архив исходников скачивается отдельно в Releases. Автоматические архивы GitHub **Source code** тоже содержат код; для установки игрокам нужен **TheDollShopRU-0.1.1.zip**.

## Проверка

Проверены установка и восстановление всех 12 файлов, повторная установка, обновление с 0.1.0, отказ при повреждённых патчах и несовместимых файлах, откат при ошибке замены, защита манифеста, пути с кириллицей и пробелами. Проверки установщика выполнялись на отдельных копиях файлов игры.
