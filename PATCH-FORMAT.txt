DSDELTA1

Патч — GZIP-поток. Все числа little-endian.

Заголовок распакованного потока:
  8 байт: ASCII DSDELTA1
  Int64: размер оригинала
  Int64: размер результата
  32 байта: SHA-256 оригинала
  32 байта: SHA-256 результата
  Int32: число команд

Команда COPY:
  byte 0, Int64 смещение в оригинале, Int32 длина

Команда ADD:
  byte 1, Int32 длина, затем указанное количество буквальных байтов

COPY берёт байты из собственных оригинальных файлов пользователя.
ADD содержит новые или изменённые фрагменты, включая русский текст.
Результат проверяется по длине и SHA-256 до замены игровых файлов.
Установщик также проверяет SHA-256 самого патча из package.json.
